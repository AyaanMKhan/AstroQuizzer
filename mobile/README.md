Basic Flutter mobile app for AstroQuizzer

Requirements:
- Flutter SDK installed
- Android SDK and an Android emulator (or real device)

Quick start:

1. Open a terminal and go to the mobile folder:

   cd mobile

2. If this is not a complete Flutter project (no android/ios folders), run:

   flutter create .

   This will generate platform folders and necessary files.

3. Run on an Android emulator or connected device:

   flutter run

Or open the workspace in VS Code and use the "Flutter (mobile)" launch configuration in .vscode/launch.json to start the app.

The main app file is at lib/main.dart and shows a simple home page with a welcome text and a "Start Quiz" button.
